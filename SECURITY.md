# Security Policy

## Supported versions

Mac Smooth Scroll is distributed as source code and as ad-hoc-signed preview
releases. Best-effort security fixes are applied to the latest preview release
and the current commit on `main`. Older previews, commits, locally modified
builds, and forks are not supported.

| Version | Supported |
| --- | --- |
| Latest preview release | Yes |
| Latest `main` | Yes |
| Older preview releases | No |
| Older commits, modified builds, or forks | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's
[private vulnerability reporting](https://github.com/ronnelb-dev/mac-smooth-scroll/security/advisories/new)
to send the report securely to the maintainer. Include:

- A description of the vulnerability and its potential impact
- The affected commit or source file
- Reproduction steps or a proof of concept
- Any suggested mitigation, if known

Remove unrelated personal information, credentials, certificates, and private
keys from the report. Reports will be reviewed on a best-effort basis. Public
disclosure should wait until a fix or coordinated disclosure plan is available.
